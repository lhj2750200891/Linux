# 05 产物挂载与部署

## 1. 产物

```
output/<IMAGE_NAME>-<YYYYMMDD>-<HHMM>.img     # ext4 镜像, 容量 = rootfs 实际大小 × 1.2
```

镜像内 `/etc/ffgo/ffver` 记录 `FIREFLY: <commit前10位>` + 构建时间 + 构建者,
用它确认镜像对应哪次提交。

## 2. 挂载成品镜像 (查看 / 修改)

镜像就是单个 ext4 文件, 直接 loop 挂载:

```
sudo mkdir -p /mnt/rfs
sudo mount -o loop output/ubuntu24_gnome_kernel6.12-*.img /mnt/rfs

cat /mnt/rfs/etc/ffgo/ffver            # 确认版本
ls /mnt/rfs                            # 与普通根文件系统无异
# ... 检查或修改任意文件 ...

sudo umount /mnt/rfs                   # 改完务必卸载
```

小改动可以直接改挂载里的文件再卸载 —— 比重跑构建快得多。

容量不够时扩容 (镜像文件变大, 文件系统跟着扩):

```
truncate -s +2G xxx.img                # 尾部加 2G 稀疏空间
sudo e2fsck -f xxx.img
sudo resize2fs xxx.img
```

## 3. 构建现场调试 (work 目录, btrfs 池内)

构建失败/中断后, rootfs 工作现场在快照池的 work 子卷里
(**注意: 是 `output/btrfs_mnt/work`, 旧文档写的 rootfs_work 已废弃**):

```
# 构建刚失败/中断: 池通常还挂着, 直接看
ls output/btrfs_mnt/work

# 若池已卸载 (重启过/构建正常结束): 手动挂池
sudo mkdir -p output/btrfs_mnt
sudo mount -o loop output/btrfs_pool.img output/btrfs_mnt

# 挂 proc/dev 进 work 后 chroot 进去 (arm64 经 qemu 转译)
sudo tools/mount-rootfs.sh -m output/btrfs_mnt/work/
sudo chroot output/btrfs_mnt/work /bin/bash
#   排查示例: /bin/systemd-sysusers; echo $?   (qemu OFD 自检, 应为 0)

# 退出后务必卸载 (顺序: 先 -u 再卸池)
exit
sudo tools/mount-rootfs.sh -u output/btrfs_mnt/work/
sudo umount output/btrfs_mnt
```

手工改过 work 后想出镜像: 直接 `sudo ./build.sh` 从断点续跑到打包即可
(前提进度标记还在); 手工打包等价于 do_package 的四步:

```
sudo dd if=/dev/zero of=out.img bs=1 count=0 seek=<du -sb work ×1.2 字节>
sudo mkfs.ext4 out.img && sudo mount -o loop out.img /mnt/rfs
sudo cp -a output/btrfs_mnt/work/* /mnt/rfs/ && sudo umount /mnt/rfs
```

> 一致性提醒: 手工改动没有对应快照, 断点续跑时会从"最后完成步骤"的快照恢复,
> **手工改动会被丢弃**。想保留就先自己打一份镜像, 或把改动固化成构建步骤。

## 4. 部署到板子

### 方式一: 进 SDK 打整固件 (常规出货路径)

```
# 把成品 img 作为 SDK 的 rootfs.img, 再走 SDK 固件编译/打包流程
# (rootfs.img 的替换位置以 SDK 固件打包流程为准, 见 SDK 适配笔记 ubuntu24.04 段)
```

### 方式二: RKDevTool 单烧 rootfs 分区 (调试最快)

```
板子进 Loader/Maskrom → RKDevTool 只勾 rootfs 分区
地址以 SDK device/.../parameter.txt 里 rootfs 分区的偏移为准
选择本 img → 执行
```

### 方式三: update.img 整包升级 (现场升级用)

SDK 的 firefly-update.sh 打整包升级固件, rootfs 已含在内。

## 5. 板端首启验证

```
# 1. 自动登录: GNOME-Wayland 桌面以 firefly:firefly 自动进桌面
# 2. 版本核对:
cat /etc/ffgo/ffver
# 3. 分区自动扩展: rockchip resize 服务首启自动扩 rootfs 分区到整卡
df -h /
# 4. 多媒体/GPU: gst-inspect-1.0 | grep rockchip;  glmark2-es2-wayland
# 5. WiFi/BT: nmcli dev wifi list;  bluetoothctl list
# 6. 屏幕键盘 onboard: 手动拉起 (自启已关)
# 7. SSH: openssh-server 已装, firefly 用户 sudo 免密成员 (sudo 组)
```
