# 01 源码获取与环境准备

## 1. 拉取源码

```
cd /media/lhj/data/t-chip/7.code/rootfs/ubuntu24.04
git clone ssh://git@git.t-firefly.com:8022/misc-develop/rootfs_build.git
cd rootfs_build
git switch master
```

仓库本体很小 (脚本+功能组+配置), 大头全在两处: `src_deb/` 子模块与 `base-package/` 基础包。

## 2. 子模块 (自编译包源码 + firefly 仓库镜像)

```
# 全部拉齐 (12 个子模块)
git submodule update --init --recursive

# 只拉构建必需的 firefly 本地仓库镜像 (构建入口也会自动同步它)
git submodule update --init src_deb/firefly-reprepro
```

| 子模块组 | 分支 | 作用 |
| --- | --- | --- |
| gstreamer1.0 / gst-plugins-{base,good,bad} / gstreamer-rockchip | ubuntu24 | GStreamer 全家桶自编译 (rockchip 补丁, 硬件编解码插件) |
| libdrm / libv4l-rkmpp / v4l-utils | ubuntu24 | 图形/视频底层库 |
| xorg-server / mutter | ubuntu24 | 显示栈 |
| firefly-binary_deb | ubuntu24 | Firefly 二进制包源目录 (ffwifibt/ffquectel/ffmisc 等, `dpkg -b` 直接打包) |
| firefly-reprepro | master | **firefly 官方 apt 源完整镜像** (reprepro 结构), 构建期本地加速的供给方 |

```
base-package/
```

- **不要改名/移动** 基础包, 配置按文件名引用。

## 4. 宿主依赖清单

| 依赖 | 要求 | 用途 |
| --- | --- | --- |
| root 权限 | 必须 (`sudo ./build.sh`) | chroot + 多种 mount (proc/sys/dev/loop/bind) |
| qemu-user-static | **>= 8.x** | 转译执行 rootfs 内 arm64 二进制, 版本决定构建成败 (见 §5) |
| btrfs-progs + 内核 btrfs | 必须 | 断点快照池 (`sudo apt install btrfs-progs; sudo modprobe btrfs`) |
| 宿主 127.0.0.1:80 端口 | 默认需可用 | 本地 firefly 源 HTTP 服务; 被占时 config 加 `export LOCAL_FIREFLY_REPO=0` 关闭加速 |
| binfmt_misc aarch64 | 自动注册 | pre_base 执行 `update-binfmts --enable qemu-aarch64` |
| python3 | 必须 | 本地源服务 `python3 -m http.server` |
| 磁盘 | 预留 ~60G | 快照池 (默认 16G 起自动扩) + apt 缓存 + 基础包 + 产物 |

```
# 本机 (WSL2 环境实测) 首次准备实录
sudo apt install -y btrfs-progs
sudo modprobe btrfs
qemu-aarch64-static --version           # 确认 >= 8.x
```

## 5. qemu 版本: 唯一的硬性坑

**原理**: pre_base 把宿主的 `/usr/bin/qemu-aarch64-static` 拷进 rootfs, 所有 chroot 内
的 arm64 二进制 (apt/dpkg/systemd-sysusers...) 都经它转译执行。

| 宿主 qemu 版本 | 结果 |
| --- | --- |
| 4.2.1 (Ubuntu 20.04 自带) | ❌ base 第一步必挂: systemd postinst 报 `Failed to take /etc/passwd lock: Invalid argument` |
| 8.2.2 (Ubuntu 24.04 noble) | ✅ 实测通过 |

**根因**: systemd-sysusers 创建系统用户前要对 `/etc/.pwd.lock` 加 OFD 锁
(fcntl 36/37/38); qemu-user 4.2.1 不转译这三个 OFD 命令, 一律返回 EINVAL。

**升级方法** (以 focal 宿主升到 noble 的 8.2.2 为例, 静态链接无依赖):

```
curl -sS -o /tmp/qemu-user-static_8.2.2.deb \
  "https://mirrors.huaweicloud.com/ubuntu/pool/universe/q/qemu/qemu-user-static_8.2.2+ds-0ubuntu1_amd64.deb"
sudo dpkg-deb -x /tmp/qemu-user-static_8.2.2.deb /tmp/qemu-new    # 解包, 不要 dpkg -i
sudo cp -n /usr/bin/qemu-aarch64-static /usr/bin/qemu-aarch64-static.org42
sudo cp /tmp/qemu-new/usr/bin/qemu-aarch64-static /usr/bin/qemu-aarch64-static
qemu-aarch64-static --version
```

> 注意: Ubuntu 22.10 之后部分版本把 qemu-user-static 拆成不含二进制的元包 (十几 KB),
> 要选含 `/usr/bin/qemu-aarch64-static` 的完整包 (约 14MB)。

**自检** (在任一 arm64 rootfs 或构建现场内):

```
sudo chroot output/btrfs_mnt/work /bin/systemd-sysusers; echo $?   # 应为 0
```
