# 03 配置与功能组

## 1. 配置的 5 个变量 (config/<profile>, 纯环境变量)

| 变量 | 语义 |
| --- | --- |
| `PACKAGE_NAME` | 基础包文件名 (base-package/ 下) |
| `SPACE_NAME` | 功能组命名空间 = `chroot/` 下的一级目录名 |
| `DO_LIST` | 空格分隔的功能组序列, 按序执行; 组内按文件名字典序执行 |
| `SOURCE_LIST_FILE` | `res/$SPACE_NAME/` 下的 apt 源文件名; 留空 = 保留基础包自带源 |
| `IMAGE_NAME` | 产物镜像产品名 (时间戳自动追加); 缺省用配置文件名 |

**当前配置由 `config/.config` 符号链接指定** (本机状态, 不提交)。
本机现状: `.config -> ubuntu24_gnome_kernel6.12`。

## 2. 六个配置总览

`./build.sh config` 菜单按文件名字典序列出 (隐藏 kylin_common):

```
1) kylin_rk3588_general            (kernel 5.10)
2) kylin_rk3588_industry           (kernel 6.1)
3) ubuntu24_clean                  # 最小系统, 验证流水线用, 最快
4) ubuntu24_gnome                  # GNOME X11, kernel 5.10
5) ubuntu24_gnome_kernel6.12       # GNOME-Wayland, kernel 6.12  <- 主力配置
```

| 配置 | DO_LIST | 产物名 |
| --- | --- | --- |
| `ubuntu24_clean` | `base last` | `ubuntu24_clean-*.img` |
| `ubuntu24_gnome` | `base firefly-pre gnome rockchip oem firefly common` | `ubuntu24_gnome-*.img` |
| `ubuntu24_gnome_kernel6.12` | `base firefly-pre gnome-wayland rockchip-for-kernel6.12 oem firefly common` | `ubuntu24_gnome_kernel6.12-*.img` |
| `kylin_rk3588_industry` | `base firefly-pre rockchip-3588 oem cleanup last` | `Kylin-Desktop-V10-Industrial-*.img` |
| `kylin_rk3588_general` | `general` (单组十一步) | `Kylin-Embedded-V10-General-*.img` |
| `kylin_common` | legacy, 菜单不显示 | - |

三个 Ubuntu 配置均 `SOURCE_LIST_FILE="ubuntu.sources"` (阿里云 noble ports)。

## 3. 步骤的三种类型 (后缀决定执行方式)

| 后缀 | 类型 | 执行方式 |
| --- | --- | --- |
| `NN_desc.apt` | 包列表 | `chroot ... /chroot/scripts/do_apt.sh <文件>`; 列表逐词扫描, `update`→apt update, `upgrade`→apt upgrade, 其余合并成一次 install; 统一 DEBIAN_FRONTEND=noninteractive |
| `NN_desc.shell` | 脚本 | chroot 内以 bash 显式执行 (无需执行位); **非 0 退出码即中断构建** |
| `NN_desc.overlay` | 目录覆盖 | `cp -rfd /chroot/.../* /` 整目录覆盖到 rootfs 根; 目录内结构必须与目标文件系统一致 |

- 文件名两位序号 = 执行顺序; 未知后缀显式报错中断 (不允许静默跳过);
- 优先级: **.apt > .shell > .overlay** (overlay 没有"包归属", 只放纯静态文件)。

## 4. ubuntu24 功能组明细 (主力配置实际执行的 7 组)

### base (系统基础)
```
1_system-user.shell   apt-get update + apt-get -f -y upgrade
2_install.apt         update upgrade vim net-tools ubuntu-minimal
                      openssh-server util-linux-extra toilet
3_autologin.shell     tty1 与串口 root 自动登录 (getty override.conf)
4_network.shell       NetworkManager 管理所有设备; mask 两个 wait-online 服务 (加速开机)
5_localhost.shell     写 /etc/hosts (127.0.0.1 localhost) / hostname=ubuntu
```

### firefly-pre (接入 Firefly 源, 必须在其它用 firefly 包的组之前)
```
1_apt-source.shell    源设为 http://wiki.t-firefly.com/firefly-ubuntu-repo noble main
                      导入签名; pin 优先级 1001 (firefly 旧版可覆盖 ubuntu 新版)
                      apt update 后重装 systemd 全家 (取 firefly 定制版)
```

### gnome-wayland (GNOME-Wayland 桌面, 配 kernel 6.12)
```
1_install.apt                     完整 GNOME 桌面包清单 (gdm3/firefox/中文字体等)
2_disable-gnome-initial-setup.shell  purge gnome-initial-setup
3_remove-update-manager.shell     删系统更新弹窗
4_disable-idle-sleep.shell        禁空闲息屏/自动挂起
5_remove-sssd.shell               删 sssd (企业登录, 板子用不到)
6_install-onboard.shell           装板编 onboard 1.4.4-6 屏幕键盘 (deb 在 onboard-debs/):
                                  uinput 注入通道 (Wayland/X11 通吃)、dconf 扩展白名单
                                  (不覆盖会丢 ubuntu-dock/桌面图标)、关自启只留手动拉起、
                                  清理每用户残留扩展的 cleanup 服务
```

### rockchip-for-kernel6.12 (Rockchip 硬件支持, 6.12 内核配套)
```
1_base.overlay         大型覆盖层: camera_engine_rkaiq、libmali GPU 驱动 (g29p1 系列:
                       bifrost-g31/g52, valhall-g310/g610, x11-wayland-gbm)、
                       rknpu2 NPU 运行时、rockchip.service/usbdevice/resize 等
                       systemd 单元、udev 规则、weston 启动器配置、profile.d 环境
                       脚本、updateEngine、ALSA UCM2、图标壁纸、npu_fw_pcie、upgrade_tool
2_system-enable.shell  启用上述服务
3_install.apt          mpp/rga/rkaiq 等 Rockchip 运行库
4_fix-gpu-permission.shell  GPU 设备节点权限修复
5_misc.shell           杂项
```

### oem (出厂定制)
```
1_adduser.shell            建 firefly:firefly 用户, 入 sudo/video/dm/cdrom/dip/plugdev/users/lpadmin 组
2_autologin.shell          桌面自动登录 firefly
3_remove-def-login-info.shell  清默认登录提示信息
4_logo.overlay             motd (00-header/10-help-text/30-sysinfo) + 壁纸
5_localhost.shell          localhost 兜底
```

### firefly (Firefly 应用包)
```
1_install.apt           ffwifibt ffquectel libffmedia ffmisc fireflydev ffaudio-config
                        (均来自 firefly 源, 源码在 src_deb 子模块)
2_udev-rules.overlay    99-drm-sn.rules (按序列号授权 DRM)
3_wifibt-ap6275p.overlay  AP6275P WiFi/BT 修复: 新版 wifibt 脚本 (6.12 内核 BT 改
                        hciattach bcm43xx 流程) + bcmdhd 固件三件套 + BCM4362A2.hcd;
                        仅检测到蓝牙 UART TTY 时接管, USB 蓝牙交内核 btusb/btrtl
4_wifibt-rtw89.overlay  RTL8852BU/B 固件 (rtw89 + rtl_bt)
```

### common (通用测试/多媒体工具)
```
1_glmark2.apt      全后端 glmark2 (GPU 跑分)
2_gstreamer.apt    gst 全家 + qt5/qt6 插件 + opencv
3_tools.apt        i2c-tools 等调试工具
4_bt-receive.apt   blueman dconf-cli (蓝牙接收)
5_bt-receive.shell 开 obex 文件接收 (dconf opp-accept=true + obex 服务链接)
```

> `chroot/ubuntu24/last/` 曾作为"收尾钩子"空组, 主力配置 DO_LIST 已不含 last;
> 功能组目录不存在时构建会显式报错, 改 DO_LIST 时注意与目录保持一致。

## 5. 三个 SPACE 互不通用

`ubuntu24` 与 `kylin` 的同名功能组 (base/oem/...) 内容互不通用, 以 SPACE_NAME
隔离, 不要跨 SPACE 复用脚本。kylin 路径还有 systemd-sysusers "假体" 历史包袱
(见 06 排障), Ubuntu 路径已清理。
