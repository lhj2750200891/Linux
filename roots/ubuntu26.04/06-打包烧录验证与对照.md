# 06 打包成镜像、烧录验证、与 rootfs_build 对照

## 1. 出镜像前清理 (手工版 do_clean)

chroot 内最后执行:

```
apt clean                                   # 清 /var/cache/apt/archives
rm -rf /var/lib/apt/lists/*                 # 清包索引 (首启 apt update 重建)
rm -f /usr/bin/qemu-aarch64-static          # 转译器是宿主工具, 不该留在成品
history -c
exit                                        # 退出 chroot
```

```
sudo $W/leave-chroot.sh                     # 卸 proc/sys/dev
```

清理哲学 (对照 rootfs_build 的 do_clean): 构建期塞进 rootfs 的一切"构建工具/临时状态",
出镜像前都要摘掉, 让每块板首启以干净姿态重建自己的状态 —— 重要的不是脚本, 是这份清单。

## 2. 打包方法一: 建空镜像 + 挂载拷入 (理解 do_package)

```
cd $W
SIZE=$(sudo du -sb rootfs | cut -f1)              # 精确字节数 (必须 -sb, 不是 -sh)
SIZE=$((SIZE * 12 / 10))                          # x1.2: ext4 元数据 + 首启写入余量
sudo truncate -s $SIZE ubuntu26-rootfs.img        # 稀疏大文件, 瞬间完成
#   (等价于 rootfs_build 用的 dd bs=1 count=0 seek=N 稀疏写法)
sudo mkfs.ext4 -F ubuntu26-rootfs.img             # 在普通文件里建 ext4
sudo mkdir -p /mnt/rfs
sudo mount -o loop ubuntu26-rootfs.img /mnt/rfs   # 镜像文件当块设备挂
sudo cp -a rootfs/. /mnt/rfs/                     # cp -a: 属主/权限/软链/设备节点全保
sudo umount /mnt/rfs
sudo e2fsck -f ubuntu26-rootfs.img                # 烧录前最后体检
```

四条理解点:

- **镜像 = 文件里的文件系统**: ext4 建在一个普通文件上, loop 挂载让它看起来像块设备;
- **du -sb**: 按实际字节算 (稀疏不虚报), 决定镜像大小必须用它;
- **x1.2 冗余**: ext4 inode/日志占位 + 首启日志/缓存写入, 20% 是经验值;
- **e2fsck -f**: 强制全检元数据, 与挂没挂过无关, 上板前的最后保险。

## 3. 打包方法二: mkfs.ext4 -d 一条命令 (现代做法)

```
SIZE=$(sudo du -sb rootfs | cut -f1); SIZE=$((SIZE * 12 / 10))
truncate -s $SIZE ubuntu26-rootfs.img
sudo mkfs.ext4 -F -d rootfs ubuntu26-rootfs.img    # 直接把目录灌进镜像, 免挂载免拷贝
sudo e2fsck -f ubuntu26-rootfs.img
```

- e2fsprogs >= 1.43 支持 -d; 与方法一结果等价, 只是灌入通道不同;
- rootfs_build 选方法一, 因为打包时还要挂载进去写 /etc/ffgo/ffver 版本戳。

## 4. 上板验证

### 烧录: 配现有 boot, 只烧 rootfs 分区 (最快闭环)

```
1. 板子进 Loader/Maskrom, RKDevTool 只勾 rootfs 分区
   地址取自 SDK device/rockchip/<板级>/parameter.txt 里 rootfs 行的偏移
2. 选择 ubuntu26-rootfs.img -> 执行
3. 串口 (1500000) 打开, 复位
```

上电前自查三件事:

- [ ] ubuntu26-rootfs.img 名义大小 <= parameter.txt 里 rootfs 分区大小 (超出会烧半截起不来)
- [ ] boot (内核/dtb) 是现用那套, `uname -r` == rootfs 里 /lib/modules 的目录名
- [ ] fstab 的根设备 == 板子实际 rootfs 分区 (03 §7 在旧板上抄的那行)

### 首启验证清单 (03/04/05 各章验收的汇总)

```
串口日志滚动          -> boot/fstab 正常
登录提示符出现        -> serial-getty@ttyFIQ0 生效
firefly 登录成功      -> 用户/密码/组正确
ip addr 有地址        -> NetworkManager 正常
ssh firefly@<板IP>    -> openssh-server 正常
df -h / 已扩满分区    -> resize 服务首启扩容成功
cat /etc/machine-id   -> 首启自生成 (非空即正常)
lsmod / ls /dev/dri   -> 04 硬件层正常
自动进 GNOME 桌面     -> 05 桌面层正常
```

### 常见首启失败对照表

| 串口现象 | 根因 | 修 |
| --- | --- | --- |
| Kernel panic: Attempted to kill init | root= 指向的分区没有可用 init (镜像没烧全/烧错分区) | 核对 parameter.txt 偏移与镜像大小 |
| Give root password for maintenance | fstab 某行失败 (设备名/格式错) | 进救援态 cat /etc/fstab, 对照上电前自查 |
| A start job is running for /dev/... | fstab 等一个不存在的设备 | 设备名与 lsblk 核对 |
| 日志走完但没有登录符 | serial-getty@ttyFIQ0 没启用 | 回 03 §6 重做, 重新打包 |
| 刷屏 failed to load module | /lib/modules 版本 != 内核 | 回 04 §2 |
| ip addr 只有 lo | network-manager 未装/未起 | 回 03 §3 |

## 5. 与 rootfs_build 对照 (教学收束)

| 本教程 | rootfs_build | 框架在你之上多做的事 |
| --- | --- | --- |
| 01 下载+SHA256 | base-package/ + pre_base | 基础包不入 git 的管理约定 |
| 01 解包 | pre_base 解包进 btrfs base/ | btrfs 池: 每步只读快照 = 断电可续跑 |
| 02 进出脚本 | do_list 内部挂载 + trap 体系 | 任何失败/断电自动卸载还原, 幽灵挂载兜底 |
| 03 §1 换源 | change_apt_source | res/ 目录按配置分发 |
| 03 §2-§9 系统层 | base/oem/firefly 功能组 | DO_LIST 顺序化, 步骤粒度=快照粒度 |
| 04 §2 模块 | rockchip-for-kernel6.12 组 | 同款 modules_install, 外加 BSP overlay |
| 04 §4 BSP+pin | firefly-pre 组 + 本地源加速 | 80 端口本地镜像, URL/签名不变, 下载提速 |
| 05 GNOME | gnome-wayland 组 | 外加 onboard 板编包/扩展白名单等踩坑成果 |
| 06 §1 清理 | do_clean | 固化成不可跳过的流程步骤 |
| 06 §2 打包 | do_package | 写 /etc/ffgo/ffver 版本戳 + 时间戳命名 |

一句话收束: **rootfs_build = 本教程这套手工流程 + 顺序化 (DO_LIST) + 可重入 (btrfs 快照)
+ 无痕化 (do_clean/trap) + 加速 (本地源/apt 缓存)**。你现在两边都通透了。

## 7. 构建期排障速查

| 现象 | 原因与处理 |
| --- | --- |
| chroot 内 dpkg 卡在 systemd-sysusers, 报 Invalid argument | 宿主 qemu < 8.x, 升级 (../ubuntu24.04/01 §5 有现成方法) |
| chroot: exec format error | binfmt 未注册: 重装 qemu-user-static 或重启 systemd-binfmt |
| apt update 报 DNS Temporary failure | resolv.conf 没换宿主的, 回 02 §3 |
| Unable to locate package / 404 | Suites 打错 (必须 resolute) 或镜像源不通 |
| apt 报证书错误 (https 源) | 先 http 源装 ca-certificates 再换 https |
| umount busy | fuser -vm 找进程, 退干净再卸; 别用 -l 硬卸掩盖问题 |
| 磁盘满 | 桌面层最吃空间; 镜像/工作区都在数据盘, df 排查 |
