# 代码修改记录：ASM1182E 第二路 RTL8852BE WiFi 移植

- 解决日期：2026-08-11
- 项目/平台：SpacemiT K3 / Firefly AIBOX-PRO / Linux 6.18.3
- 修改目标：使 ASM1182E 第二下行口连接的 RTL8852BE WiFi 与 USB 蓝牙组合模组正常供电、枚举并完成 WiFi DMA 初始化。

## 修改概览

| 文件 | 位置 | 修改目的 |
| --- | --- | --- |
| `arch/riscv/boot/dts/spacemit/aibox-pro-test.dtsi` | `FF_ASM1182e_PCIE0_WIFI` | 配置 WiFi 电源、WiFi/BT 禁用控制和 PCIe CLKREQ# |
| `arch/riscv/boot/dts/spacemit/aibox-pro-test.dtsi` | `&resmem`、`&pcie3_rc` | 为 ASM1182E 后方的 32-bit DMA 设备提供低地址 DMA 窗口 |

## 修改 1：增加 WiFi/BT 模组板级控制

文件：`arch/riscv/boot/dts/spacemit/aibox-pro-test.dtsi`  
位置：`FF_ASM1182e_PCIE0_WIFI`

修改前：测试文件中不存在第二扩展口 WiFi/BT 模组对应的电源、rfkill 和 CLKREQ# 配置。

修改后：

```dts
/ {
#ifdef FF_ASM1182e_PCIE0_WIFI
	vcc3v3_wifi: regulator-vcc3v3-wifi {
		compatible = "regulator-fixed";
		regulator-name = "vcc3v3_wifi";
		regulator-min-microvolt = <3300000>;
		regulator-max-microvolt = <3300000>;
		gpios = <&gpio K3_GPIO(99) GPIO_ACTIVE_HIGH>;
		enable-active-high;
		startup-delay-us = <100000>;
		regulator-boot-on;
		regulator-always-on;
		pinctrl-names = "default";
		pinctrl-0 = <&wifi_pwr_en_cfg>;
		status = "okay";
	};

	rfkill_wifi: rfkill-wifi {
		compatible = "rfkill-gpio";
		label = "rfkill-pcie-wlan";
		radio-type = "wlan";
		shutdown-gpios = <&gpio K3_GPIO(127) GPIO_ACTIVE_LOW>;
		pinctrl-names = "default";
		pinctrl-0 = <&wifi_disable_cfg>;
		status = "okay";
	};

	rfkill_bt: rfkill-bt {
		compatible = "rfkill-gpio";
		label = "rfkill-usb-bt";
		radio-type = "bluetooth";
		shutdown-gpios = <&gpio K3_GPIO(73) GPIO_ACTIVE_LOW>;
		pinctrl-names = "default";
		pinctrl-0 = <&bt_disable_cfg>;
		status = "okay";
	};
#endif
};

&pcie3_rc {
	pinctrl-names = "default";
	pinctrl-0 = <&pcie3_wifi_clkreq_cfg>;
};
```

对应 pinctrl 使用 GPIO99、GPIO127、GPIO73，以及 GPIO107 function 5（`K3_PCIED_CLKREQN`）。未重复配置已经移植成功的 CH344P USB 链路。

## 修改 2：增加 PCIe restricted DMA pool

文件：`arch/riscv/boot/dts/spacemit/aibox-pro-test.dtsi`  
位置：`&resmem`、`&pcie3_rc`

修改前：

```dts
#ifdef FF_ASM1182e_PCIE0_WIFI
/* ASM1182E upstream is configured by FF_ASM1182e_PCIE0_M2. */
&pcie3_rc {
	pinctrl-names = "default";
	pinctrl-0 = <&pcie3_wifi_clkreq_cfg>;
};
#endif
```

修改后：

```dts
#ifdef FF_ASM1182e_PCIE0_WIFI
&resmem {
	pcie3_dma_pool: pcie3-dma-pool@1f0000000 {
		compatible = "restricted-dma-pool";
		reg = <0x1 0xf0000000 0x0 0x02000000>;
	};
};

&pcie3_rc {
	pinctrl-names = "default";
	pinctrl-0 = <&pcie3_wifi_clkreq_cfg>;

	dma-ranges = <0x02000000 0x0 0x80000000
		      0x1 0xf0000000
		      0x0 0x02000000>;
	memory-region = <&pcie3_dma_pool>;
};
#endif
```

修改说明：保留 32 MiB 物理内存 `0x1f0000000`，并将其映射到 PCIe 侧的 32-bit 地址 `0x80000000`，使 RTL8852BE 能成功分配 TX/RX DMA ring。

## 最终结果

- DTS 预处理和 DTB 编译通过；新增 reserved-memory、`dma-ranges` 和 phandle 均正确生成。
- ASM1182E 第二下行口枚举 RTL8852BE `[10ec:b852]`。
- `rtw89_8852be` 成功绑定并生成 `phy0`、`wlan0`。
- 2.4 GHz 和 5 GHz AP 扫描正常。
- NetworkManager 连接、DHCP 地址获取及公网 ping 验证成功。
- USB 蓝牙设备、`btusb` 驱动和 RTL8852BU 固件加载正常。
