# 代码修改记录：ASM1182E第一路NVMe移植

- 解决日期：2026-08-11
- 项目/平台：SpacemiT K3 / AIBOX-PRO / Linux 6.18
- 修改目标：通过 ASM1182E 两口 PCIe switch 枚举第一路 M.2 NVMe SSD

## 修改概览

| 文件 | 位置 | 修改目的 |
| --- | --- | --- |
| `arch/riscv/boot/dts/spacemit/aibox-pro-test.dtsi` | ASM1182E 电源、复位、PCIeD/PHY4、pinctrl | 建立 K3 到 ASM1182E 的 Gen2 x1 上游链路并保证上电复位时序 |

## 修改 1：增加 ASM1182E 电源和复位时序

文件：`arch/riscv/boot/dts/spacemit/aibox-pro-test.dtsi`  
位置：根节点临时测试配置

修改前：

```dts
/ {
#ifdef FF_ASM1182e_PCIE0_M2

#endif
};
```

修改后：

```dts
/ {
#ifdef FF_ASM1182e_PCIE0_M2
	asm1182e_power: regulator-asm1182e-power {
		compatible = "regulator-fixed";
		regulator-name = "asm1182e_power";
		regulator-min-microvolt = <3300000>;
		regulator-max-microvolt = <3300000>;
		gpios = <&gpio K3_GPIO(106) GPIO_ACTIVE_HIGH>;
		enable-active-high;
		pinctrl-names = "default";
		pinctrl-0 = <&asm1182e_pwr_en_cfg>;
		startup-delay-us = <100000>;
		regulator-boot-on;
		regulator-always-on;
		status = "okay";
	};

	asm1182e_perst_release: regulator-asm1182e-perst-release {
		compatible = "regulator-fixed";
		regulator-name = "asm1182e_perst_release";
		regulator-min-microvolt = <3300000>;
		regulator-max-microvolt = <3300000>;
		gpios = <&gpio K3_GPIO(87) GPIO_ACTIVE_HIGH>;
		enable-active-high;
		pinctrl-names = "default";
		pinctrl-0 = <&asm1182e_perst_cfg>;
		vin-supply = <&asm1182e_power>;
		startup-delay-us = <100000>;
		regulator-boot-on;
		regulator-always-on;
		status = "okay";
	};
#endif
};
```

修改说明：GPIO106 同时使能 ASM1182E 的 3.3 V 和 1.2 V 电源；GPIO87 释放低有效上游 PERST#。级联 fixed-regulator 保证先上电并等待 100 ms，再释放复位并等待 100 ms。

## 修改 2：配置正确的 PCIeD 和 PHY4

文件：`arch/riscv/boot/dts/spacemit/aibox-pro-test.dtsi`  
位置：`phy4`、`pcie3_rc`

修改前（首次尝试，板端链路为 down）：

```dts
&phy3 {
	status = "okay";
};

&pcie2_rc {
	phys = <&phy3>;
	phy-names = "phy3";
	num-lanes = <1>;
	max-link-speed = <2>;
	vpcie3v3-supply = <&asm1182e_perst_release>;
	status = "okay";
};
```

修改后：

```dts
&phy4 {
	status = "okay";
};

&pcie3_rc {
	phys = <&phy4>;
	phy-names = "phy4";
	num-lanes = <1>;
	max-link-speed = <2>;
	vpcie3v3-supply = <&asm1182e_perst_release>;
	status = "okay";
};
```

修改说明：原理图上游复位网络标注为 `K3_PCIED_PERSTN`，对应 K3 Port D，即 `pcie3_rc + phy4`。ASM1182E 为 Gen2 x1 switch，因此限制为 `max-link-speed = <2>`、`num-lanes = <1>`。

## 修改 3：增加 GPIO pinctrl

文件：`arch/riscv/boot/dts/spacemit/aibox-pro-test.dtsi`  
位置：`&pinctrl`

修改前：

```dts
&pinctrl {
#ifdef FF_ASM1182e_PCIE0_M2

#endif
};
```

修改后：

```dts
&pinctrl {
#ifdef FF_ASM1182e_PCIE0_M2
	asm1182e_pwr_en_cfg: asm1182e-pwr-en-cfg {
		asm1182e-pwr-en-pins {
			pinmux = <K3_PADCONF(106, 0)>;
			bias-disable;
			drive-strength = <25>;
			power-source = <1800>;
		};
	};

	asm1182e_perst_cfg: asm1182e-perst-cfg {
		asm1182e-perst-pins {
			pinmux = <K3_PADCONF(87, 0)>;
			bias-disable;
			drive-strength = <25>;
			power-source = <1800>;
		};
	};
#endif
};
```

修改说明：GPIO106 和 GPIO87 配置为 1.8 V GPIO 输出，分别控制电源使能和上游复位释放。

## 最终结果

DTS 编译通过。板端 PCIeD/PHY4 链路训练成功，ASM1182E 上游口、两个下游 bridge 和第一路 SM2261XT NVMe SSD 均被枚举；系统生成 `/dev/nvme0n1` 和分区 `nvme0n1p1`。
