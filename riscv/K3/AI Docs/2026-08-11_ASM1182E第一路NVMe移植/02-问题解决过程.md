# 问题解决过程：ASM1182E第一路NVMe移植

- 解决日期：2026-08-11
- 环境：SpacemiT K3 AIBOX-PRO，Linux 6.18，ASM1182E 两口 PCIe Gen2 switch，M.2 NVMe SSD

## 问题现象

目标是通过 ASM1182E 扩展出的第一路 PCIe 接口连接 M.2 NVMe SSD。最初配置 `pcie2_rc + phy3` 后，设备树状态、regulator 和 PHY PLL 均正常，但内核提示：

```text
spacemit-k1-pcie 80800000.pcie: spacemit-pcie: link is down after host_init
```

`lspci` 只能看到 K3 Root Port，看不到 ASM1182E 和 NVMe SSD。

## 最终根因

根据 `PCIE4-2.jpg` 原理图，ASM1182E 上游复位信号明确标注为 `K3_PCIED_PERSTN`。这说明上游高速链路属于 K3 PCIeD，对应设备树中的 `pcie3_rc + phy4`，而不是首次使用的 `pcie2_rc + phy3`。错误 PHY 虽然可以锁定自身 PLL，但物理上没有连接 ASM1182E，因此链路始终为 down。

## 关键排查过程

1. 检查运行设备树，`pcie@80800000` 和 `phy-pcie@82000000` 都是 `okay`，排除 DTB 未更新。
2. regulator summary 显示 `asm1182e_power` 和 `asm1182e_perst_release` 均已启用；PHY 日志显示 PLL Locked，说明 GPIO106 电源和基础 PHY 初始化已执行。
3. 首次日志仍为 `link is down after host_init`，且 `lspci` 没有 ASMedia bridge，故问题位于 K3 到 ASM1182E 的上游链路，而非下游 SSD。
4. 复核原理图 Q22 附近的 `K3_PCIED_PERSTN` 标注，确认控制器应改为 Port D，即 `pcie3_rc + phy4`。
5. 更换控制器和 PHY 后，内核枚举出 `[1b21:1182]` ASM1182E 上游/下游 bridge 及 `[126f:2261]` NVMe endpoint。

## 解决方案

- GPIO106 用 fixed-regulator 使能 ASM1182E 的 3.3 V/1.2 V 电源。
- GPIO87 用级联 fixed-regulator 在电源稳定后释放低有效 PERST#。
- 上游控制器配置为 `pcie3_rc`，使用 `phy4`，链路限制为 PCIe Gen2 x1。
- 不为两个 ASM1182E 下游口分别建立 SoC PCIe 控制器节点；下游 bridge 和 SSD 由 PCI core 自动枚举。

## 验证结果

- 验证方法：检查 regulator、PCIe/PHY 启动日志、`lspci -Dnn`、`lspci -Dtv` 和 `lsblk`。
- 验证结果：

```text
spacemit-k1-pcie 80c00000.pcie: spacemit-pcie: link is up after host_init
pci 0003:01:00.0: [1b21:1182] PCIe Switch Upstream Port
pci 0003:02:03.0: [1b21:1182] PCIe Switch Downstream Port
pci 0003:02:07.0: [1b21:1182] PCIe Switch Downstream Port
pci 0003:03:00.0: [126f:2261] PCIe Endpoint
nvme nvme0: pci function 0003:03:00.0
nvme0n1: p1
```

ASM1182E 工作在 5.0 GT/s、PCIe x1，上游可用带宽约 4.0 Gb/s；`lsblk` 显示 119.2 GiB 的 `nvme0n1`。

## 可复用经验

- K3 PCIe 移植不能只根据接口名称推断 PHY；应同时核对高速差分对和 `PERST#` 网络名，`PCIED` 对应 `pcie3_rc + phy4`。
- PHY PLL Locked 只说明 PHY 自身初始化成功，不能证明物理链路选对；是否出现 switch/endpoint 才是上游链路有效的证据。
- PCIe switch 的下游端口由 PCI core 自动枚举，设备树通常只需要配置 SoC 上游控制器、电源和复位时序。
