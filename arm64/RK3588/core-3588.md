## 2. 核心参数（RK3588 芯片）

工艺：8nm LP

| 模块 | 参数 |
|---|---|
| CPU | 4×Cortex-A76 @2.4GHz + 4×Cortex-A55 @1.8GHz |
| GPU | Mali-G610 MP4（OpenGL ES 3.2 / Vulkan 1.2 / OpenCL 2.2） |
| NPU | 6 TOPS，3 核（INT4/INT8/INT16/FP16） |
| 解码 | 8K@30 H.265/VP9/AV1，可拆 32 路 1080p@30 并行 |
| 编码 | 8K@30 H.264/H.265 |
| ISP | 48MP，支持 3 帧 HDR |

| 接口 | 能力 |
|---|---|
| 内存 | LPDDR4/LPDDR4x/LPDDR5，最大 32GB |
| 存储 | eMMC（HS400） |
| 显示输出 | HDMI2.1 TX ×2（8K@30/4K@120）、MIPI-DSI ×2（4K@60）、eDP1.3、DP1.4（Type-C Alt Mode） |
| 视频输入 | HDMI2.0 RX ×1（4K@60）、MIPI CSI-2 ×2 |
| PCIe | PCIe3.0 x4（可拆 2×x2 / 4×x1） + PCIe2.1 x1 ×3（与 SATA3/USB3 复用） |
| SATA | SATA3.0 ×3（复用） |
| USB | USB3.1 Gen1 OTG ×1（Type-C，含 DP1.4 Alt Mode）、USB3.0 Host ×1、USB2.0 Host ×2、USB2.0 OTG ×1 |
| 以太网 | 2× GMAC（需外挂 PHY） |
