# Firefly WK2xxx SPI 转 UART 驱动(spi-wk2xxx)

ROC-RK3588S-PC 扩展板 SPI 转 4 路 UART(WK2124/WK2164/WK2168 家族)驱动。
注册 `/dev/ttysWK0..3`(扩展板用途:WK0/1 = RS485×2,WK2/3 = RS232×2)。

## 来源与移植

- 6.1.118 SDK 中该驱动以**预编译目标文件**形态存在:`kernel/drivers/spi/spi-wk2xxx_64`
  (ELF relocatable,无源码,`drivers/spi/Makefile` 里 `spi-wk2xxx-objs := spi-wk2xxx_64` 直接链接)。
- **预编译 .o 不可跨内核版本链接**:6.12 删除了 `struct uart_state.xmit`(circ_buf),
  旧二进制按旧偏移访问会写坏相邻成员,必须用源码重编。
- 本目录 `spi-wk2xxx.c` = WKIC 原厂 v2.5 源码(与 6.1 二进制同族,`compatible "firefly,spi-wk2xxx"`)
  移植到 6.12,移植点:
  1. 发送缓冲:`uart_state->xmit`(circ_buf)→ `tty_port.xmit_fifo`(kfifo),TX 路径改 kfifo_out/kfifo_len/kfifo_is_empty;
  2. `of_get_named_gpio_flags` 在 6.12 已删除 → `of_get_named_gpio`;
  3. `spi_driver.remove` 回调 6.12 起返回 void;
  4. `uart_ops.set_termios` 第三参数加 const;
  5. `kfifo_out` 返回值必须消费(warn_unused_result)。
- 配置:`CONFIG_SPI_WK2XXX=y`(`firefly-linux.config` 原有此行,符号现由本目录 Kconfig 提供)。

## 编译挂接

```
drivers/misc/Kconfig        -> source "drivers/misc/firefly/Kconfig"
drivers/misc/Makefile       -> obj-y += firefly/
drivers/misc/firefly/Kconfig  -> source "drivers/misc/firefly/wk2xxx/Kconfig"   (定义 CONFIG_SPI_WK2XXX)
drivers/misc/firefly/Makefile -> obj-$(CONFIG_SPI_WK2XXX) += wk2xxx/
drivers/misc/firefly/wk2xxx/Makefile -> obj-$(CONFIG_SPI_WK2XXX) += spi-wk2xxx.o
```

## 设备树绑定(ROC-RK3588S-PC ext 板实例)

```dts
&spi1 {
	status = "okay";
	pinctrl-0 = <&spi1m2_cs0 &spi1m2_pins>;   /* 必须:硬件片选 GPIO1_D3 + 时钟 GPIO1_D2 */
	num-cs = <1>;

	spi_wk2xxx@0 {
		compatible = "firefly,spi-wk2xxx";
		reg = <0>;                             /* 子串口不在此区分,驱动内部用 iobase 1..4 */
		spi-max-frequency = <10000000>;        /* WK 上限 10MHz */
		reset-gpio = <&gpio3 RK_PA6 GPIO_ACTIVE_HIGH>;  /* WK2124_RST(当前驱动配置未启用,靠板上默认拉高) */
		irq-gpio   = <&gpio3 RK_PC6 IRQ_TYPE_EDGE_FALLING>; /* WK2124_INT */
		cs-gpio    = <&gpio1 RK_PD3 GPIO_ACTIVE_HIGH>;  /* 参考,未启用,片选走硬件 CS0 */
	};
};
```

## 6.1 中的驱动调用链路(移植版逻辑相同)

### 装载(probe)

```
DTS 匹配 compatible "firefly,spi-wk2xxx"
 └→ wk2xxx_probe(spi_device)
     ├─ spi_setup:8bit / SPI_MODE_0 / ≤10MHz
     ├─ wk2xxx_spi_irq_parse_dt:of_get_named_gpio(GPIO3_C6) → gpio_to_irq
     ├─ SPI 通路自检:GENA(0x00)回读校验 (val&0xF0)==0x30,失败则 probe=-ENODEV
     ├─ kthread_worker 创建(kthread_run "wk2xxx",SCHED_FIFO 半实时优先级)
     ├─ uart_register_driver(&wk2xxx_uart_driver)   major=207, dev_name="ttysWK"
     ├─ 4 × uart_port 填充:iobase=1..4(片上子串口号)、ops=&wk2xxx_pops、
     │   uartclk=11059200(晶振)、fifosize=256 → uart_add_one_port → /dev/ttysWK0..3
     └─ devm_request_irq(GPIO3_C6 下降沿,IRQF_TRIGGER_FALLING)
```

### 打开(open → startup)

```
wk2xxx_startup:
 GENA 置对应子串口使能位 → GRST 复位位 → GIER 全局中断使能
 SIER 收中断(RFTRIG+RXOUT) → SCR TXEN/RXEN → FCR 0xFF/0xFC 复位 FIFO
 SPAGE=1 下写 RFTL(收触发 0x40)/TFTL(发触发 0x01),SPAGE=0 回页 0
```

### 参数(set_termios)

```
tty_termios_baud_rate 取波特率 → 按 uartclk=11.0592M 算分频:
 temp = freq/(baud*16)-1 → BAUD1(高8位)/BAUD0(低8位),小数部分 → PRES
 LCR:数据位/停止位/校验 → conf_wk2xxx_subport 在 SPAGE=1 页写入 BAUD/PRES
```

### 发送

```
应用层 write → tty/uart 核心 → tty_port.xmit(circ_buf,6.1)
 → ops->start_tx = wk2xxx_start_tx → kthread_queue_work(start_tx_work)
 → wk2xxx_start_tx_proc:SIER 置 TFTRIG_IEN(使能发送 FIFO 触发中断)
 → 芯片 INT 拉低 → wk2xxx_irq(硬中断,只做排队)
 → kthread_worker 执行 wk2xxx_ist:读 GIFR 判定活动的子串口
 → wk2xxx_port_irq:读 SIFR/SIER
 → wk2xxx_tx_chars:
     FSR/TFCNT 查 TX FIFO 剩余空间(≤256,限 200)
     6.1:手动从 state->xmit.buf[tail] 逐字节搬、tail 环形推进
     wk2xxx_write_fifo:命令 ((port-1)<<4)|0x80,
       每批 ≤ SPI_LEN_LIMIT(30) 字节批量 SPI 传输
     发完且 pending < WAKEUP_CHARS → uart_write_wakeup;全空 → stop_tx(清 TFTRIG_IEN)
```

### 接收

```
RX FIFO 到触发水位/溢出 → INT → 同一条中断链
 → wk2xxx_rx_chars:
     读 RFCNT 得字节数(两次取大,0 视为 256)
     wk2xxx_read_fifo:命令 0xC0|((port-1)<<4),批量 SPI 读(每批 ≤30)
     FSR 高 4 位错误掩码:PE/FE/OE/BI → icount 统计 + TTY_PARITY/FRAME/OVERRUN/BREAK
     uart_handle_sysrq_char → uart_insert_char → tty_flip_buffer_push
```

### 寄存器模型(贯穿所有路径)

- 全局寄存器:GENA(子串口时钟使能)/GRST(复位)/GIER(中断使能)/GIFR(中断标志)
- 子串口寄存器分两页:SPAGE=0(SCR/LCR/FCR/SIER/SIFR/TFCNT/RFCNT/FSR/LSR/FDAT/FWCR/RS485)、
  SPAGE=1(BAUD1/BAUD0/PRES/RFTL/TFTL/流控阈值)
- SPI 命令字节:读 = 0x40|((port-1)<<4)|reg,写 = ((port-1)<<4)|reg;
  FIFO 读 = 0xC0 组合,FIFO 写 = 0x80 组合
- 所有寄存器访问由全局 mutex `wk2xxxs_reg_lock` 串行化;片选由 SPI 控制器硬件 CS0 驱动
  (6.1 与本移植版均未启用手工 cs-gpio 模式,CONFIG_SPI_WK2XXX_GPIO_* 全关)
```
