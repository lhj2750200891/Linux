# 接口功能验证指南

> 分两层: msh 内置命令(默认固件就有) + common tests 测试组件(menuconfig 里开)
> 通用外设详细验证步骤还可查 `Rockchip-docs/develop/common/` 每个外设的 PDF(多数带验证章节)

---

## 0. 前提: 开启测试组件

EVB defconfig 默认**不开**测试组件。要跑测试命令需重配:

```bash
cd <SDK>/bsp/rockchip/rk2118
cp board/evb1_v20/defconfig .config
scons --menuconfig
#   → RT-Thread Common Test case
#     → [*] Enable BSP Common TEST
#         勾选需要的: I2C / SPI / GPIO / SNOR / SPINAND / WDT / TIMER / DMA /
#         AUDIO / DISPLAY / SUSPEND / DSP / UART(TEARIOS) / USAGE ...
# 保存后固化回板级并重编:
cp .config board/evb1_v20/defconfig
./build.sh board/evb1_v20/package-file rtt0     # 单编 cpu0
./mkimage.sh board/evb1_v20/package-file        # 打出 Image/rtt0.img
# 烧 cpu0_os_a: wl 0x2200 ./Image/rtt0.img
```

测试源码都在 `bsp/rockchip/common/tests/`,可先读源码看每个命令怎么测、测哪个设备。

## 1. 先看软件层: 设备都注册了吗

```text
msh > list_device        # 所有 rt_device(uart/i2c/spi/pin/mtd/sd0/...)
msh > list_thread        # 线程
msh > version / free / ps
```

设备没出现在 list_device 里 → 先查 menuconfig 有没有开对应驱动(`RT_USING_I2CN` 等),不用急着测硬件。

## 2. 默认固件就有的命令(不用开测试组件)

| 命令 | 验证的东西 | 用法示例 |
|---|---|---|
| `pin` | GPIO | `pin read 20` / `pin write 20 1` / `pin mode 20 output`(引脚号=BANK_PIN 换算) |
| `io` | **任意寄存器**读写(终极手段) | `io 0x40460000`(读 UART0) / `io 0x40460000 0x12345678`(写) |
| `get_temp` | TSADC 温度 | `get_temp 0`(带 channel) |
| `opp_dump` | DVFS/OPP 档位 | `opp_dump` |
| `vendor_test` | vendor storage | `vendor_test r 1`(读 SN) |
| `mem_bw_test` | 内存带宽 | `mem_bw_test r/w/c` |
| `cpu_stress` | CPU 压测 | `cpu_stress` |
| `cmb_test` | 崩溃栈回溯 | `cmb_test DIVBYZERO` |
| `reboot loader` | 进烧写模式 | — |
| `mount` / `ls` / `df` | 存储与文件系统 | `mount` 看挂载表 |

## 3. 按接口验证矩阵(EVB V20 硬件对照)

### 串口类
| 接口 | 开关(测试) | 命令 | 验证方法 |
|---|---|---|---|
| UART0 debug | 默认 | — | 看到启动日志+shell 即通过 ✅ |
| 其它 UART(UART1-3) | RT_USING_COMMON_TEST_UART | `termios_test` | 板上引出 TX/RX **短接回环**自发自发 |

### 总线类
| 接口 | 开关 | 命令 | 验证方法 |
|---|---|---|---|
| I2C | RT_USING_COMMON_TEST_I2C | `i2c_test read i2c2 0x20 0x1234 2 32`<br>`i2c_test write i2c1 0x20 0x1234 2 0xf5f5f5f5 4` | 对板上**已知器件地址**读 ID(如板载 codec);读得到合法值=通 |
| SPI | RT_USING_COMMON_TEST_SPI | `spi_test` | 回环或接 flash |
| SPI NAND(EVB V20 主存储) | RT_USING_COMMON_TEST_SPINAND | `spinand_test` | 读写擦校验 |
| SPI NOR | RT_USING_COMMON_TEST_SNOR | `snor_test` | SFDP/读写擦 |

### 模拟与定时类
| 接口 | 开关 | 命令 | 验证方法 |
|---|---|---|---|
| SARADC | (drv_saradc 默认) | `saradc_test` | EVB 按键(V+/V-/PRE/NEXT…)多为 ADC key,按键看电压变化;万用表对照 |
| PWM | RT_USING_PWM | `rt_pwm_set` msh 命令 | 输出到端子,示波器/万用表看占空比 |
| TIMER | RT_USING_COMMON_TEST_TIMER | `hw_timer_test` | — |
| WDT | RT_USING_COMMON_TEST_WDT | `wdt_test` | 喂狗/不喂狗复位对比 |
| DMA | (随驱动) | `dma_test` | — |
| TSADC | RT_USING_TSADC | `get_temp` | 数值合理(常温 25-50℃) |

### 音频类(EVB V20 重点)
| 接口 | 开关 | 命令 | 验证方法 |
|---|---|---|---|
| 播放(SAI+codec+功放→喇叭) | RT_USING_COMMON_TEST_AUDIO | `tinyplay /xxx.wav -D <card>` | 接 Headphone 或 SPK 端子听音;partybox demo 出声即链路通 ✅ |
| 录音(PDM mic 阵列) | 同上 | `tinycap /data/rec.wav -c 4` | 录完 `tinyplay` 回放听 |
| SPDIF TX/RX | RT_USING_AUDIO_CARD_SPDIF* | tinyplay 对应 card | 光纤对接 |
| 音频自动初始化 | — | `list_device` 看 audio card | 启动日志有 sound card 注册信息 |

### 存储与外设扩展
| 接口 | 开关 | 命令 | 验证方法 |
|---|---|---|---|
| USB Host(标准A口) | RT_USING_DWC2_USBH | 插 U 盘 → `mount` | 出现 /udisk 挂载,`ls /udisk` |
| SD 卡 | RT_USING_SDIO0 | 插卡 → `mount` | /sdcard |
| eMMC(可选配) | RT_USING_EMMC | `mount`/`spinand_test` 类比 | — |
| 网口 RMII(RJ45) | lwip + GMAC | `ping <PC_IP>` | 网线连 PC/交换机;EVB defconfig 已带 lwip |
| Display 连接器 | RT_USING_COMMON_TEST_DISPLAY / MODETEST | `display_test` / `modetest` | 接屏看彩条/图案 |
| IR 红外 | RT_USING_PWM_REMOTECTL_TEST | `remote_control_test` | 拿遥控器按键看打印键值 |
| 按键 | — | `saradc_test` / `pin read` | 按 MASKROM/RESET 之外的系统键观察 |
| BT 模组(BT5.3) | bt/rkstack(third_party) | 应用层 | 进阶,见 third_party/bt |

### 多核与系统级
| 项 | 开关 | 命令 | 验证方法 |
|---|---|---|---|
| DSP 核 | 默认 | `dsp_cmd` | 启动日志三行 `Hello RK2118 dsp0/1/2` ✅ |
| Mailbox | RT_USING_COMMON_TEST_MBOX | `mbox_test` | — |
| RPMSG | RT_USING_COMMON_TEST_RPMSG_LITE | `rpmsg_master_test` | — |
| Crypto | RT_USING_COMMON_TEST_CRYPTO | `crypto` | 加解密自测 |
| 低功耗 suspend | RT_USING_COMMON_TEST_PM | `suspend_test` 系 | `timer_wakeup` / `gpio_wake <bank> <pin>`,测电流变化用 Power Test 座 |
| DVFS | RT_USING_OPP | `opp_dump` | 配合 cpu_stress 看频率变化 |

## 4. 调试技巧

1. **没输出先查软件**: `list_device` 没有该设备 → menuconfig 开驱动再编,别怀疑硬件
2. **i2c/spi 不通**: 先 `io` 直接读外设 ID 寄存器验证总线时序,再查 iomux(board/<板>/iomux.c)引脚复用对不对
3. **终极手段**: `io` 命令直接读写外设基址寄存器(基址表见笔记 09),绕过驱动逐位排查
4. **HAL 级测试**: `bsp/rockchip/common/hal/` 有 unity 测试框架,裸机工程 `hal/project/rk2118/`(TestDemo)可脱离 RT-Thread 验证寄存器级
5. **外设详细验证步骤**: `Rockchip-docs/develop/common/` 下每外设 PDF(如 Rockchip_Developer_Guide_RT-Thread_I2C_CN.pdf)多数带"测试验证"章节
6. 测试命令具体参数:多数不带参数运行会打印 usage;或直接读 `common/tests/<x>_test.c` 源码(百行级,一目了然)
