# 驱动层

> 三层结构: **RT-Thread 设备框架 (drv_*.c) → Rockchip HAL (hal_*.c) → 寄存器 (soc.h/rk2118.h)**
> rk2118 目录下没有本地驱动源码(`drivers/` 只有 Kconfig),全部复用共享驱动池 `bsp/rockchip/common/drivers/`

---

## 2. 核心驱动实现要点

| 驱动 | RTT 设备框架 | 关键点 |
|---|---|---|
| `drv_uart.c` | serial V1 | `DEFINE_ROCKCHIP_UART(ID)` 宏展开;DMA 收发;用 `g_uartNDev`(hal_bsp 提供) |
| `drv_gpio.c` | pin 设备 | 引脚号 `BANK_PIN(GPIO_BANKn, pin)`;5 个 GPIO bank;IRQ 表 `pin_irq_hdr_tab[]` |
| `drv_i2c.c` | i2c bus | `rockchip_i2c_xfer()`;`g_i2cNDev` |
| `drv_spi.c` | spi bus | spi0~spi4 + `drv_spi2apb.c`(spislv 从机,SPI2APB 升级通道) |
| `drv_pwm.c` | pwm 设备 | `rt_pwm_set/get` |
| `drv_saradc.c` | adc 设备 | `rt_adc_enable/read`;事件同步 |
| `drv_wdt.c` | watchdog | `rt_pm_device_register()` PM 感知 |
| `drv_clock.c` | (非设备框架) | `clk_set_rate(eCLOCK_Name, rate)` / `clk_enable(gate)` / `pd_power(pd, on)` — CRU API |
| `drv_pm.c` | RT-Thread PM 组件 | `pm_runtime_request()`;配套 `drv_dvfs.c`、`drv_opp.c` |
| `drv_thermal.c` | TSADC | OTP trim 校准;500ms 周期监控 |
| `drv_snor.c` | MTD NOR | SFDP 探测;FSPI host;**XIP 启动主存储路径** |
| `drv_dsp.c/dsp.c` | rt_dsp 设备 | 旧一代 MBOX work 框架("for pisces") — **RK2118 用 hifi4 的 DRP 新框架**,此为遗留 |
| `interrupt.c` | 中断适配 | PROF_IRQ hook 测中断耗时 |
| `drv_cache.c` | — | cache 维护(+ECC 变体) |
| `drv_usage.c` | — | CPU 占用率 |

## 3. 寄存器基址速查(soc.h 风格)

HAL 用 `#define XXX_BASE 0x40xxxxxx` + `struct XXX_REG` + `#define XXX ((struct XXX_REG*)XXX_BASE)`,代码直接 `UART0->...`、`GRF->...` 访问。

```
UART0=0x40460000     I2C2=0x40410000     SPI1=0x404C0000      SPI2APB=0x40A50000
GPIO0~4=0x40B5/404E/404F/4050/4051_0000
SAI0-7=0x40600000~0x40830000    PDM=0x40700000    SPDIFRX0/1=0x4072/0x4092_0000
SPDIFTX0=0x40900000    ASRC0-7=0x4068~0x408B_0000    FIR/IIR_ACC=0x40CC0000/0x40CC2000
SARADC=0x40A70000   TSADC=0x407C0000   WDT0-4=0x4026~0x402A_0000
TIMER0-19=0x402C~0x40303000    MBOX0-15=0x40240000~    SPINLOCK=0x40220000
INTMUX0-11=0x40320000~    CRU=0x40B00000    PMU=0x40B20000
CRYPTO=0x40000000   TRNG=0x4001/0x4012_0000   CAN=0x400A0000
MMC0/1=0x4018/0x40A0_0000   VOP=0x40190000   GMAC=0x40A40000   OTPC=0x40A60000
FSPI=0x40A10000     FLEXBUS=0x401A0000
安全态另有 0x4xxx 映射(非安全 0x5xxx, 如 PMU_SRAM=0x50B40000)
```

## 4. 音频驱动架构 (common/drivers/audio/)

ASoC 风格(`rk_audio.c` 中间层):

```
audio_card {name, dai, codec, codec_master, playback, capture, format, mclkfs}
   ↓                ↓
struct audio_dai_ops   struct audio_codec_ops
(init/set_clk/config/start/stop/prepare)  (+set_gain/get_gain)
```

- **v2 驱动(RK2118 用)**: drv_sai.c、drv_mdais.c、drv_mpcm.c、drv_pdm.c、drv_spdifrx/spdiftx.c、drv_i2stdm.c
- **v1 遗留**: drv_i2s.c、drv_pcm.c、drv_vad.c、drv_audiopwm.c
- **PCM 核心**(`pcm/` 子目录): ALSA 式 pcm.c/pcm_hw/pcm_plugin/pcm_softvol
- **通用 codec**(common): es8311/8388/8156/7243、aw8896 功放、rk730、acdcdig(内置)
- **rk2118 专用 codec**(`components/hifi4/rtt/codecs/`): tas6424、tas5805m、ak5736vn、ad2428(A2B)、aw85805、es7202/es7210、rk751、rk_dummy_audio_card
- 板级声卡表: `board/common/audio_base.c` 的 `rk_board_audio_cards[]`(SAI0~7, mclkfs=256)

RK2118 硬件音频资源: 8×SAI(I2S/PCM/TDM,SAI0/4 支持 4 lane)、PDM 8 mic、SPDIF TX1/RX2、ASRC×8、FIR/IIR 加速器(4096 阶 FIR/64 biquad IIR,hal_facc)。
