# 板级配置与板卡变体

> 目录: `bsp/rockchip/rk2118/board/`
> 结构: 每板一个目录(defconfig + board.c + iomux.c + 打包文件),公共逻辑在 `board/common/`(board_base.c 等,各板 board.c 用 RT_WEAK 覆盖)

---

## 1. 板卡变体一览

| 板目录 | 硬件 | 存储 | 运行 | 说明 |
|---|---|---|---|---|
| `evb` | RK_EVB1_RK2118G_V10 | **SPI NOR** | DDR | 主基线板,HIFI4 partybox demo,littlefs root |
| `evb1_v20` | EVB1 V20/V21 (2024-04/10) | **SPI NAND** | DDR | A/B 双分区(OTA) |
| `evb1_v20_nor` | EVB1 V20 NOR 版 | SPI NOR | DDR | secure boot check,soft timer |
| `evb3_v10` | EVB3 V10 (2024-07) | SPI NAND | DDR | A/B 双分区 |
| `evb_emmc` | — | **eMMC** | DDR | 只有配置/打包文件,复用 BOARD_EVB |
| `evb_nand` | — | SPI NAND | — | 只有配置/打包文件,复用 BOARD_EVB |
| `adsp_demo` | 车载 DSP (EV2/M, 2024-01/04) | SPI NOR | **XIP** | 车载,有 audio_pipe 变体 |
| `adsp_ddr_demo` | 车载 EVB4/M2 (2024-09) | SPI NOR(DDR idb) | DDR | audio_pipe / npu_demo 变体,双核 |
| `soundbar_core` | Soundbar 核心板 | SPI NOR | DDR | HIFI4 partybox |
| `fpga` | FPGA 仿真 | 无 flash | XIP | 最简 board.c(78 行),uart0 1.5M |
| `iotest` | IO 压测 | SPI NOR | XIP | uart0+uart2,双核 |
| `test1` | 测试板 | SPI NOR | XIP | 仅 board.c/iomux/defconfig |
| `common` | 公共代码 | — | — | board_base/clk_base/iomux_base/mnt_base/audio_base |

时钟配置按芯片型分(`RT_USING_CLK_CONFIG0/1/2`):
- **CONFIG0** = RK2118M;**CONFIG1** = RK2118M2(带 DDR);**CONFIG2** = RK2118G/RK2118B
- DSP0 OPP: M=700MHz@1.0V,G=800MHz@1.1V(PVTM+OTP 校准,GPIO0_A5/A6 控制 dcdc 电压);DSP1/2 = 491.52MHz@0.9V(M)
- CONFIG0 时钟:GPLL 800M、VPLL0 983.04M、SFC XIP 先 25M 后 50M、SAI MCLK 12.288M、TSADC 12M

## 2. 每板文件构成

```
board/<板>/
├── defconfig             cpu0/rtt0 配置源
├── cpu1_defconfig        cpu1 配置(如有)
├── defconfig_recovery    recovery 固件配置(secure 态)
├── defconfig_audio_pipe / defconfig_npu_demo   变体(部分板)
├── board.c / board.h     板级初始化(RT_WEAK 覆盖 common/board_base.c)
├── iomux.c / iomux.h     引脚复用(补充 iomux_base.c)
├── setting.ini           Firmware.img 分区(NOR 车载)
├── parameter.txt         update.img 分区(GPT, 含 FIRMWARE_VER)
├── package-file          update.img 内容清单
└── part.txt              mkparameter.py 输入
```

板级 Kconfig 选择(`board/Kconfig`):`RT_USING_BOARD_XXX`(choice)+ 通常 select `RT_USING_DDR`;root 文件系统 `RT_ROOT_PARTITION_USE_LITTLEFS`。

## 3. 公共板级代码 (board/common/)

### board_base.c — 启动流程核心

```
rt_hw_board_init():
  mpu_init()            MPU 6 个 region(code/data/device 0x50000000-0x50DFFFFF/heap/ddr/spi2apb)
  HAL_Init() → BSP_Init()
  cmbacktrace 初始化
  SysTick 挂 systick_isr, HAL_SetTickFreq(1000/RT_TICK_PER_SECOND)
  iomux 引脚复用
  rt_memory_heap_init()  CPU0: SRAM 堆 + "ddr" memheap; CPU1: DDR 堆
  uart 控制台(g_uart0_board, 1500000 波特)
  clk_init(clk_inits)    时钟表
  sai_mclkout
  console
  idle hook (WFI, NOHZ 可选)
  rt_components_board_init()

_start → entry()  (启动入口)
```

MSH 命令 `cpu1 enable/disable`:操作 PMU->INT_MASK_CON 的 MCU1_RST_DIS 释放/锁住 cpu1。

### 其它公共文件

- `clk_base.c` — 三套 clk_init 表(CONFIG0/1/2),PLL/总线/DSP/SAI 时钟初始化
- `mnt_base.c` — mount_table:littlefs 模式挂 "mtd_root"→"/",否则 "root"→"/"(FAT);SDIO0 时 sd0→"/sdcard"
- `iomux_base.c` — 公共 IOMUX(RMIO/IOMUX),各板 iomux.c 补充(如 evb: i2c0 GPIO0_A6/A7 RMIO、UART1 GPIO3_C2~C5 RM1)
- `audio_base.c` — SAI/codec 公共配置
- `setting.ini` — 公共默认分区模板

## 4. 新建板级(官方 Quick Start 步骤)

1. 复制模板:`board/evb`(SPI Nor)/ `board/evb1_v20`(nand)/ `board/evb_emmc`(eMMC)
2. 改 `board/Kconfig`:加 `RT_USING_BOARD_XXX` + select 需要项(如 RT_USING_DDR)
3. 改 `board/SConscript` 依赖
4. 修改/复制 defconfig,menuconfig 调好后 `cp .config board/<板>/defconfig` 存回
5. 按 flash 类型准备 parameter.txt/package-file 或 setting.ini
6. `./build.sh board/<板>/package-file` 验证

## 5. 默认 rtconfig.h 现状

`bsp/rockchip/rk2118/rtconfig.h` 当前是 **adsp_demo 菜单的保存产物**(helloworld HIFI4 demo):CORE0 + XIP + SNOR(120MHz, XIP data @0x50000)+ CLK_CONFIG0 + UART0(console)+ I2C0 + HIFI4(helloworld_demo)。真正的板级配置以各 `board/*/defconfig` 为准。

### evb/defconfig 亮点(与默认的差异)

RT_NAME_MAX 16、串口接收缓冲 1024、DFS+ELMFAT+LITTLEFS、USB HOST、NEW_OTA(A_RECOVERY 模式)、CLK_CONFIG2、HIFI4 EVB_PARTYBOX_DEMO、RT_ROOT_PARTITION_USE_LITTLEFS。

## 6. applications/main.c — 应用入口

```
启动链: Reset_Handler → _start (board_base.c) → entry() → RT-Thread 启动 → main()
```

- **CPU0**: 打印 "this is cpu0";读固件版本(`get_rk_partition_fw_ver()`,来自 genfwver.py 注入的 firmware_version)打印 FIRMWARE_VER;非 recovery 且 RT_USING_NEW_OTA 时调 `rk_ota_set_boot_success()` 标记启动成功
- **CPU1**: 打印 "this is cpu1"
- 可选 RK_USING_MISC_TEST:寄存器读延迟 / cpu_stress(CoreMark)/ mem_bw_test 带宽测试

用户应用一般写在 `applications/main.c` + 用 `INIT_APP_EXPORT`/`MSH_CMD_EXPORT` 注册,或直接加新文件到 applications/(SConscript 自动编入)。
