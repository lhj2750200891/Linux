### Quick Start 关键结论(摘自 Rockchip_RK2118_Quick_Start_RT-Thread_CN V1.0.7)

- **内核**: RK2118 使用 RT-Thread v4.1.1x
- **环境**: 64 位 Ubuntu 20.04/18.04(Windows 用 WSL)
- **工具链**: `arm-gnu-toolchain-13.2.Rel1-x86_64-arm-none-eabi`,用 `export RTT_EXEC_PATH=.../bin` 指定
- **依赖**: `sudo apt-get install gcc-arm-embedded scons clang-format astyle build-essential dosfstools fusefat python3 python3-pip`
- **XIP 注意**: rtconfig.py 默认开 XIP;编非 XIP 固件(SPI nand/eMMC)要把 rtconfig.py 中 "XIP" 改成 "W"
