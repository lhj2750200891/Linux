# 编译构建与镜像打包

> 所有脚本在 `bsp/rockchip/rk2118/` 下执行(**没有顶层 build.sh**,SDK 根目录只是源码树)
> 完整流程文档: `Rockchip-docs/manuals/rk2118/Rockchip_RK2118_Quick_Start_RT-Thread_CN.pdf`

---

## 1. 环境准备

```bash
# 工具链(强制要求此版本,build.sh 会校验)
export RTT_EXEC_PATH=/path/to/arm-gnu-toolchain-13.2.Rel1-x86_64-arm-none-eabi/bin

# 依赖
sudo apt-get install gcc-arm-embedded scons clang-format astyle build-essential \
                     dosfstools fusefat python3 python3-pip lzma   # lzma 需 ≥9.22
```

工具链参数(`rtconfig.py`):

```
ARCH='arm'  CPU='cortex-m33'  CROSS_TOOL='gcc'   # RTT_CC 环境变量可覆盖
PREFIX='arm-none-eabi-'
DEVICE = -mcpu=cortex-m33 -mthumb -mfpu=fpv5-sp-d16 -mfloat-abi=hard \
         -ffunction-sections -fdata-sections
CFLAGS = $DEVICE -g -Wall -Werror -D__RT_THREAD__     # release -Os / debug -O0 -gdwarf-2
LFLAGS = $DEVICE -lm -lgcc -lc -specs=nano.specs -specs=nosys.specs -nostartfiles \
         -Wl,--gc-sections,-Map=rtthread.map,-cref,-u,Reset_Handler
```

## 2. 一键编译: build.sh

```bash
cd <SDK>/bsp/rockchip/rk2118

./build.sh board/evb/package-file                # EVB 消费类 → Image/update.img
./build.sh board/adsp_demo/setting.ini           # 车载 NOR → Image/Firmware.img
./build.sh board/evb1_v20/package-file           # SPI NAND A/B 版
./build.sh board/adsp_ddr_demo/setting_root.ini  # M2 DDR 车载版

# 单固件编译
./build.sh board/evb/package-file rtt0|rtt1|recovery|rtt0_b

# 指定音频框架/demo 变体
./build.sh board/adsp_demo/setting.ini audio_pipe
./build.sh board/evb/package-file soundbar|partybox|gamebar|audio_pipe|rkstudio_test|npu_demo
```

**build.sh 内部流程**:

1. 校验 `RTT_EXEC_PATH` 必须是 arm-gnu-toolchain-13.2.Rel1
2. `genfwver.py <parameter.txt> ../common/fwmgr/fw_analysis.c` — 把 FIRMWARE_VER 写成版本变量
3. 按 package-file/setting.ini 里出现的固件,逐个编译(通常顺序 cpu1 → recovery → cpu0):

```
每个固件的编译循环:
  scons -c                          # 清理
  cp board/<板>/defconfig .config   # cpu1 用 cpu1_defconfig, recovery 用 defconfig_recovery
  scons --menuconfig                # (交互式,可跳过微调)
  scons --useconfig=.config         # 生成 rtconfig.h
  scons -j$(nproc)                  # 编译 → rtthread.elf/bin
  POST_ACTION: objcopy → align_bin_size.sh (512B 对齐) → rename_rtt.py
               (按 rtconfig.h 宏改名为 rtt0/rtt1/rtt0_b/recovery)
```

4. `mkroot.sh` — 打 root.img(资源分区)
5. `mkimage.sh` — 打包最终镜像

## 3. menuconfig 与配置文件关系

```
board/<板>/defconfig      ← 各板真实配置(保存源)
        │ cp 为 .config
        ↓
scons --menuconfig        ← 图形配置(改完保存回 .config,可 cp 回 defconfig)
        ↓
scons --useconfig=.config → 生成 rtconfig.h(编译实际引用)
```

- 没改选项时:`scons --useconfig=.config` 强制重生成 rtconfig.h
- 清理:`scons -c`;顽固时 `rm -rf build`
- **XIP 切换**:rtconfig.py 默认 XIP;编非 XIP 固件(SPI nand/eMMC)要把 rtconfig.py 里 "XIP" 改成 "W"(build.sh 会按 setting 里是否含 rk2118_idb_ddr.img 自动设 RTT_BUILD_XIP=Y/N)

Kconfig 顶层选择(`bsp/rockchip/rk2118/Kconfig`):
- `RK2118_CPU_CORE0/CORE1` — CPU 核选择(默认 CORE0)
- `CPU_RUN_IN_XIP / SRAM / DDR` — 运行空间(默认 XIP)
- `ARCH_ARM_CORTEX_SECURE` — Core0 跑 secure 态(默认 n)

## 4. 打包脚本一览

| 脚本 | 作用 |
|---|---|
| `mkfirmware.sh <setting.ini>` | NOR 固件:boot_merger 出 IDB → package_image.py 加 RESC 头 → mkini.py 回填分区大小 → firmware_merger 合成 Firmware.img |
| `mkimage.sh` | 两用:无参出缺省 Firmware.img;带 setting.ini 出 Firmware.img(含 misc.img),带 package-file 出 update.img(afptool -pack + rkImageMaker -RK2118 封装) |
| `mkroot.sh` | root.img:FAT(fusefat 拷贝 + mkfs.fat)或 LittleFS(RT_ROOT_PARTITION_USE_LITTLEFS,块 4096);NAND userdata 用 dhara_utils |
| `mkdsp.sh <proj>_dspN build` | 编 DSP 固件(Xtensa xplorer,需 export XTENSA_INSTALL_PATH),调 components/hifi4/tools/xplorer-builder |
| `mkparameter.py <part.txt> <offset>` | part.txt → RK CMDLINE 分区串(nor offset 0x80,nand/emmc 0x0) |
| `mkini.py <setting.ini>` | 按文件实际大小回填 PartOffset/PartSize(16KB 对齐) |
| `mkmisc.py <size_kb>` | 生成全零 misc.img |
| `package_image.py` | 核心:ELF .vectors 与分区偏移校验、判断 XIP(.xip_flag==0x55aaaa55)、给 rtt/tfm/dsp img 加 **RESC 头**(MAGIC "RESC", SHA256, LOADING_ADDRESS) |
| `package_idb.py` | idb 补零到 64KB 并写双份(128KB 备份) |
| `package_ota_img.sh` | OTA 包:各 img lzma -5 压缩 → afptool → update_ota.img.lzma |
| `package_ota_img_sign.sh` | 同上 + 签名(sign_tool cc/lk/ss/sf/sl,flag 0x20) |
| `sign.py` | 单套固件签名封装(chip 2118, key ../tools/sign_tool/private_key.pem) |
| `genfwver.py` | FIRMWARE_VER x.y.z → uint32 (x<<24\|y<<16\|z) 写入 fw_analysis.c |
| `rename_rtt.py` | rtthread.bin → rtt0/rtt1/rtt0_b/recovery.bin(按 rtconfig.h 宏) |
| `align_bin_size.sh` | 512B 大小对齐 |
| `mkpackage.sh` | 发布归档:repo patches + manifest + elf/map/config + DSP 源,输出 IMAGE/<日期>/ 目录 |

## 5. 产物位置

编译后 BSP 根:`rtt0.bin/.elf`、`rtt1.bin/.elf`、`rtt0_b.*`、`recovery.bin/.elf`、`rtthread.map`
`Image/` 目录:
- 静态:`config/*.json`(RESC 头配置:rtt0=0x01060800、tfm_s=0x01030800 等加载地址)、`rk2118_ddr.ini`/`rk2118_no_ddr.ini`(boot_merger 配置)
- 生成:`rtt0/1.img`、`tfm_s.img`、`cpu1_loader.img`、`dsp0/1/2.img`、`root.img`、`misc.img`、**`update.img` 或 `Firmware.img`**、`MiniLoaderAll*.bin`、`rk2118_idb_*.img`

## 6. 启动链与固件组成

```
Boot ROM → rk2118_idb_*.img (IDBlock: MiniLoaderAll, DDR init)
         → tfm_s.img        (cpu0_secure_a 分区, TF-M secure 侧, 预编译于 rkbin/)
         → cpu1_loader.img  (cpu1_secure, XIP 场景)
         → rtt0.img (cpu0_os_a)  → rtt1.img (cpu1_os_a, 可选)
         → dsp0/1/2.img     (HiFi4 DSP 固件, 预编译或自编)
         → rkstudio.img     (音效参数)
         → root.img / userdata
```

签名链:boot ROM → IDB → tfm_s → 各固件;`rkbin/` 存放预编译 loader/TFM 二进制(tfm_s.bin XIP 版 / tfm_s_ddr.bin / tfm_s_mini_a/b 等)。

## 7. secure_fw (TF-M 非安全侧)

`bsp/rockchip/rk2118/secure_fw/`:TF-M **NS 接口包**(secure 固件本体是预编译的 tfm_s*.bin):
- `include/`: config_tfm.h、tfm_ns_interface.h、tfm_rk_service_api.h、psa/(client.h error.h...)、os_wrapper/
- `lib/`: libtfm_s_veneers.a(XIP)/ libtfm_s_veneers_xip_off.a — secure 侧 veneers 预编译库
- `src/`: tfm_tz_psa_ns_api.c、tfm_rk_service_api.c、os_wrapper/tfm_ns_interface_rtos.c 等
- 应用侧通过 PSA API 调 secure 服务(密码、OTP、固件完整性校验等)
